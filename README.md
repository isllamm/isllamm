## 👨‍💻 About Me

I'm a **Senior Mobile Engineer** focused on Android, building apps that are fast, stable, and easy to use.
I've been writing code (and fixing my own bugs 😅) since **2017**.

Today I build and release **merchant-facing apps** used in real businesses every day — on phones and on **POS terminals**.
I care about clean architecture, reusable UI, and releases that go out without surprises.

## 🚀 What I've Done

- 📱 **Own releases for 3 production apps** — CashiMobile, CashiLite, and Cashi PAX (POS terminal app). Versioning, signing, store submission, and rollout.
- 🏗️ **Led an architecture migration** from Kotlin Multiplatform to native Android using Hilt, Retrofit, OkHttp, Room, Jetpack Compose, and Navigation Compose — with a modular setup based on *Now in Android*.
- 🎨 **Rolled out a new design system** across two apps to match the company brand, working closely with UI/UX designers.
- 🧾 **Shipped to POS hardware** — APK signing and PAXSTORE submission for payment terminals.
- 🛠️ **Fixed hard build problems**, like the Google Play **16 KB page size** requirement on Android 15 (native `.so` alignment).
- ⚙️ **Improved CI/CD** on Bitbucket Pipelines, including build reports and release automation.
- 🤝 **Mentored teammates** and onboarded engineers onto KMP and our app codebase.
